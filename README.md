# Flight-control-development-and-flight-testing-for-eVTOL
Flight-control development and flight testing for a ducted-fan electric vertical takeoff and landing (eVTOL) aircraft.
1.Completed airframe configuration and control allocation based on Pixhawk 6C flight controller
2.Designed control allocation logic for thrust and control surfaces
3.Implemented attitude loop, position loop, stable hovering and trajectory tracking
